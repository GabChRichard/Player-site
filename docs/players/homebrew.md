# Homebrew Rules

A few table rules that differ from the Starfinder 2e book. This list will grow as the campaign goes.

## "Action!"

When the GM says **"Action!"**, it's time to roleplay. The table switches to in-character play.

## Drift Engines

Drift Engines need **1 minute to charge**, and the jump requires the ship to be at **full speed**.

The ship does *not* need to spend a minute with its thrusters off before it can jump into the Drift.

## Custom rules added 

- Paragon skill (1 skill and 1 lore auto-scale)
- Free archetype
